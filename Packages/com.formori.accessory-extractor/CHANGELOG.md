# 변경 기록

## v1.0.1

- VCC(VPM) 패키지 `com.formori.accessory-extractor`로도 배포합니다. VCC로 설치하면 이전 unitypackage 설치 폴더(`Assets/AccessoryPrefabMaker`)를 자동으로 정리합니다.
- 여러 오브젝트를 한 프리팹으로 분리: PhysBone이 몸 Collider(Chest 등)를 가리키는 메쉬(가방 등)가 "외부 참조" 오류로 저장되지 않던 문제를 고쳤습니다. 간단 모드·각각 분리와 같이 복사 범위 밖 Collider는 자동으로 뺍니다.
- 심화 모드 UV 패널을 스크롤하면 UV가 창 머리 위에 겹쳐 그려지던 문제를 고쳤습니다.

## v1.0.0 — 정식 출시

- 첫 정식 버전입니다. v0.9.1의 기능을 그대로 담았습니다.
  - 메쉬 하나 분리(간단·심화 모드)
  - 여러 오브젝트 각각 분리
  - 여러 오브젝트를 한 프리팹으로 분리
  - 여러 몸 관절 메쉬의 MA Merge Armature 출력
- 출력 설정에 **결과 위치** 옵션을 추가했습니다: **원본 따라가기** / **바닥(원점)에 놓기**.
  - 바닥: 원본 위치를 무시하고 아바타 기준으로 반듯하게 세워 바닥 중앙에 저장합니다. 씬에 추가하면 아바타 발밑(없으면 월드 원점)에 놓입니다.
  - MA 부착·몸 관절(Merge Armature) 결과는 항상 원본 따라가기로 저장하고 경고로 알립니다.
  - 메인 창(메쉬 하나 분리, 여러 오브젝트 각각 분리)과 한 프리팹으로 분리 창 모두 지원합니다. 레시피에도 저장됩니다.
- 두 창 상단에 로고 배너(アクセサリー分離ツール · ACCESSORY EXTRACTOR)와 버전(`FORMORI · v1.0.0`)을 표시합니다. 창 탭에도 아이콘이 붙습니다. 배너는 에디터 다크/라이트 스킨에 맞춰 바뀝니다.
- 배포 패키지에는 툴 코드와 README·CHANGELOG만 넣었습니다. 테스트와 내부 검증 기록은 소스 보관본에만 있습니다.

## v0.9.1

- 기능 이름을 "분리"로 통일했습니다.
  - 메인 창 옵션: **여러 오브젝트 각각 분리**
  - 다중 창(이전 "여러 메쉬 합치기"): **여러 오브젝트를 한 프리팹으로 분리**
  - 출력 방식: **메쉬 하나로 병합** / **프리팹으로 묶기**
- 다중 창의 기본 프리팹 이름 접미사를 `_Combined`에서 `_Set`으로 바꿨습니다.

## v0.9.0

- 메인 창 `FORMORI > Accessory Extractor`의 1번 카드에 **오브젝트 선택으로 분리하기** 옵션(v0.9.1부터 "여러 오브젝트 각각 분리")을 추가했습니다.
  - 켜면 Hierarchy에서 선택한 오브젝트들과 그 자식의 메쉬 목록이 표시됩니다(여러 개 선택 가능).
  - **프리팹 저장 (N)**을 누르면 메쉬마다 간단 모드 설정으로 악세사리 프리팹을 하나씩 저장합니다. 이름은 메쉬 오브젝트 이름을 씁니다.
  - **검사**는 저장하지 않고 메쉬별 통과·실패를 표시합니다. 실패한 메쉬는 저장할 때 건너뛰고 이유를 표시합니다.
  - "저장 후 씬에 추가"를 켜면 배치까지 하고, 일괄 배치는 Ctrl+Z 한 번으로 되돌아갑니다. 원본은 유지합니다.

## v0.8.0

- 여러 몸 관절에 웨이트된 메쉬(브로치·초커·가터·의상 파츠 등)를 추출할 수 있습니다. 메쉬가 쓰는 아마추어(의상 Armature 또는 아바타 Armature)를 복사하고 MA Merge Armature를 붙여, 빌드할 때 원본 의상과 같은 방식으로 아바타 몸에 합칩니다. Modular Avatar가 필요합니다.
- 다른 몸 관절을 Source로 쓰는 Constraint(예: 팔을 따라가는 자켓 패널)가 있으면 같은 방식으로 출력합니다. Constraint가 계속 동작합니다.
- 원본의 FX 애니메이션(토글·기믹)과 Contact 기믹은 오류가 아니라 경고로 알립니다. 복사본에는 연결되지 않습니다.
- 편집 창:
  - 다른 아바타의 원본을 지정하면 아바타 루트를 다시 찾습니다.
  - 선택 중인 원본의 이동 기즈모가 표시되지 않습니다.
  - 다른 툴이 쓰는 마지막 Scene 뷰를 가로채지 않습니다.
  - Unity 재시작 후 세션 없이 복원된 창은 자동으로 닫힙니다.
  - 박스 모드에서 클릭하면 면 하나를 선택합니다.
  - 가림 판정은 첫 히트 삼각형 기준입니다.
  - 원본이 바뀌면 슬롯 필터를 초기화합니다.
  - 브러시 한 획은 Undo 한 단계로 정확히 되돌아갑니다.
- 작업 보존:
  - 스크립트 재컴파일이나 Play 진입 후 원본·선택·설정을 복원합니다. 메쉬가 바뀌었으면 선택은 복원하지 않습니다.
  - 심화 → 간단 → 심화로 전환해도 부분 선택이 유지됩니다.
- 성능:
  - UV 아일랜드를 한 번에 계산해 캐시합니다.
  - UV 패널을 한 번의 GL 패스로 그립니다.
  - 브러시는 획마다 화면 투영을 한 번만 합니다.
  - 설정 창은 입력이 있을 때만 Undo 스냅샷을 남깁니다.
- 출력 데이터:
  - 서브메쉬 수보다 많은 추가 패스 머티리얼(아웃라인 등)을 유지합니다.
  - 단일 추출에서도 sorting·motion vector·활성 상태·레이어를 복사합니다.
  - 1차원 UV를 지원합니다.
  - 병합할 때 노멀·탄젠트가 없는 파트는 계산값으로 채웁니다. 스킨 bounds는 root bone 기준으로 계산합니다.
- 기타:
  - 고정 모드에서 메쉬를 움직이던 Constraint·PhysBone이 빠지는 경우 경고합니다.
  - 형제 이름이 겹쳐 경로가 모호해도 저장합니다. 이 경우 레시피는 세션 전용이 됩니다.
  - 자동 이름은 "Closet" 같은 정리용 폴더 대신 MA 의상 루트 이름을 씁니다.
  - 남아 있던 한국어 고정 오류 메시지와 Undo 이름을 3개 언어로 옮겼습니다.

## v0.7.1

- Blender FBX 본의 스케일 노이즈(예: 1, 1, 1.000016)를 비균일 스케일로 차단하지 않습니다. 허용 오차를 상대 1e-4로 변경했습니다.
- MA Merge Armature로 아바타에 합쳐지는 의상 본(Chest·Neck·Upper_arm 등)을 몸 관절로 판정합니다. 여러 몸 관절에 웨이트된 의상 메쉬를 몸 본이 고정된 복제본으로 만들던 문제를 막습니다. 의상 Chest에 부착하는 경우 MA Bone Proxy는 아바타 Chest를 가리킵니다.
- 몸 본(Head·Chest)에 직접 부착하는 악세사리는 그 본에 붙은 Collider·Contact·헤어 PhysBone을 복사하거나 검사 사유로 삼지 않습니다.
- 성능: 창이 2초마다 메쉬 전체를 해시하던 동작을 가벼운 변경 키 비교로 바꿨습니다. 전체 해시는 검사·미리보기·저장 때만 계산합니다. 해시 값은 이전과 같아 기존 레시피가 그대로 동작합니다.
- 성능: 검사가 로드된 모든 씬 대신 아바타와 그 상위 Animator만 확인합니다. 브러시를 시작할 때 포즈가 바뀌지 않았으면 편집 씬을 다시 만들지 않습니다.
- 간단 모드는 복사 범위 밖의 몸 Collider를 자동 제외하고 경고로 안내합니다.
- 본 웨이트가 없는 SkinnedMeshRenderer는 자동으로 고정 모드를 사용합니다. 여러 메쉬 합치기에서도 같습니다.
- 여러 메쉬 합치기의 고정 메쉬 검사는 그 메쉬를 실제로 움직이는 PhysBone/Constraint만 확인합니다. 상위 본의 Collider로는 차단하지 않습니다.
- 원본 메쉬의 FX 토글·쉐이프키 애니메이션은 오류가 아니라 경고로 표시합니다. 복사된 본을 움직이는 애니메이션은 계속 차단합니다.
- 테스트: 그룹 없는 `Undo.PerformUndo()`를 그룹 단위 되돌리기로 바꿔, 테스트가 사용자 작업을 되돌릴 수 없게 했습니다.

# 변경 내역

## v0.4.1

- PhysBone이 포함한 계층에 다른 외부 호스트 PhysBone이 있으면 그 설정도 함께 복사합니다. 직접 웨이트가 없는 종속 가지가 검사에서 누락되던 문제를 수정했습니다.
- 원본 아바타·의상이 꺼져 있어도 독립 프리팹의 외부 설정 호스트가 함께 꺼지지 않도록, 호스트와 부착점의 공통 부모 아래에서 활성 상태를 보존합니다.

## v0.4.0

- Unity 및 VRC의 Parent / Position / Rotation / Scale / Aim / LookAt Constraint 복사를 지원합니다.
- 별도 오브젝트에 있는 VRC Constraint는 제어 대상이 복사 범위에 있을 때 함께 가져옵니다. Source·Target·Up 참조가 복사 본 계층 안에 있으면 필요한 연결 계층도 포함하고 새 본으로 연결합니다.
- 활성 상태, 가중치, 축, 오프셋 등 직렬화된 설정을 보존합니다. 참조 재연결이 끝나기 전에는 결과 루트를 비활성화합니다.
- 외부 참조가 해결되지 않는 Constraint와 Animator에서 제어하는 복사 대상은 계속 검사합니다. 원본 본을 참조하기만 하고 다른 대상을 제어하는 무관한 Constraint는 차단 사유에서 제외합니다.
- 실제 `Piercing` Acc 영역의 `Ear_Const` 복사와 형상 보존을 확인했습니다.

## v0.3.0

- SkinnedMeshRenderer를 지정하면 기본으로 **본 포함 복사 / 웨이트로 자동 추적**을 사용합니다.
- 선택한 면의 정점에 0보다 큰 웨이트를 가진 본을 추적하고 연결 부모 계층을 복사합니다. 불필요한 본 가지는 제외하며 원본 메쉬·본·다른 Renderer 연결은 유지합니다.
- PhysBone이 제어하는 계층은 웨이트 없는 끝 본까지 유지합니다. 별도 오브젝트에 설정된 PhysBone도 루트 참조를 따라 복사합니다. 지원되지 않는 외부 참조는 검사에서 안내합니다.
- 창에 자동 본 루트, 부착 위치, 웨이트 본 수와 복사 계층 수를 표시합니다. 자동 추적을 끄면 기존 수동 지정을 사용할 수 있습니다.
- 자동 추적에서는 공유 본도 독립 복사합니다. 원본 본의 개별 Animator/Constraint 동작을 새 본에 리타기팅하는 기능은 포함하지 않습니다. 여러 Humanoid 관절에 걸친 선택은 차단합니다.
- 선택 레시피에 자동 추적 설정을 저장하며 기존 레시피는 수동 설정으로 복원합니다.

## v0.2.0

- 결과 이름을 의상·헤어 프리팹 이름에서 자동 생성합니다. 아바타 자체가 프리팹이면 아바타 바로 아래의 의상 가지 이름을 사용하고, 독립 Renderer는 자신의 이름을 사용합니다. 파일명에 사용할 수 없는 문자는 치환합니다.
- ‘메쉬 편집’ 버튼으로 전용 Unity Scene 뷰가 열립니다. 원본을 복제한 임시 메쉬만 표시하고 선택 결과를 설정 창·UV와 공유합니다. 창 종료·재컴파일 시 임시 씬과 메쉬를 정리합니다.
- 전체 선택 A, 해제 Alt+A, 연결 아일랜드 L, 박스 선택 B, 브러시 C, 전체 맞춤 F를 지원합니다.
- 면·아일랜드 클릭과 박스 선택은 교체, Shift는 추가, Ctrl은 제외입니다. 브러시는 Shift 없이 여러 획을 계속 누적하고, Ctrl을 누르면 제외합니다. 마우스를 떼거나 빈 공간을 칠해도 앞서 선택한 면은 유지됩니다. 브러시 드래그 하나는 Undo 한 번으로 되돌립니다. 드래그 중 Esc로 시작 전 선택을 복원합니다. L은 커서 아래 조각을 추가하고 Shift+L은 제외합니다.
- 박스·브러시는 면의 중심을 기준으로 선택합니다. 관통 선택을 켜면 가려진 면도 포함합니다. 끄면 원본 메쉬의 앞에 보이는 면만 선택합니다.
- 아일랜드 선택은 가져오기 과정에서 UV·노멀 경계로 분리된 동일 위치의 모서리도 연결합니다. 완전히 겹치는 모서리를 가진 별도 조각 역시 연결로 간주하므로 그 경우 면/박스 선택을 사용하세요.
- 와이어 표시, 머티리얼 슬롯 필터, 브러시 크기 조절을 편집 창에 배치했습니다.
- 설정 창은 작은 입력칸, 단일 크기 배율, 접을 수 있는 위치·회전/고급 설정/UV/레시피로 정리했습니다.
