# 악세사리 분리 툴 v1.0.2

의상·헤어 안의 리본, 브로치, 머리핀 등의 면을 Scene 또는 UV에서 선택하고 새 메쉬와 프리팹으로 복사하는 Unity Editor 도구입니다. 본 포함 복사는 선택 정점의 웨이트에서 필요한 본·연결 부모·부착 위치를 자동 추적합니다. 원본은 그대로 유지합니다.

## 설치와 시작

VCC(VRChat Creator Companion)로도 설치할 수 있습니다. VCC에서 FORMORI 저장소를 추가한 뒤 프로젝트에 `FORMORI Accessory Extractor`를 추가하세요. unitypackage로 설치했던 `Assets/AccessoryPrefabMaker` 폴더는 VCC가 자동으로 정리합니다.


Unity 2022.3에서 패키지를 임포트하거나 이 폴더를 `Assets/AccessoryPrefabMaker`로 복사합니다. 상단 `FORMORI > Accessory Extractor`를 실행합니다.

기본 추출은 Unity Editor만 사용합니다. PhysBone 유지에는 VRChat Avatars SDK, MA 부착 출력에는 Modular Avatar가 필요합니다. 설치되지 않은 SDK·MA 타입을 직접 참조하지 않으므로 기본 도구는 해당 패키지 없이도 컴파일되도록 구성했습니다. 사용법은 함께 제공되는 튜토리얼(FORMORI_Accessory_Extractor_Tutorial.html)을 참고하세요.

## UI와 언어

### 여러 오브젝트를 한 프리팹으로 분리

메인 창 상단 **여러 오브젝트를 한 프리팹으로 분리 ↗**에서 원본 Renderer를 두 개 이상 추가합니다. 오브젝트 드래그 또는 선택 오브젝트 추가도 지원합니다. 오브젝트를 넣으면 자식의 MeshRenderer/SkinnedMeshRenderer를 목록에 추가하며 중복 추가를 방지합니다.

- **메쉬 하나로 병합:** 한 SkinnedMeshRenderer로 합칩니다. 서로 다른 루트의 좌표·바인드포즈·모든 본 웨이트를 변환합니다. 머티리얼별 슬롯과 UV 채널을 보존하고, 쉐이프키는 `1_원래이름`, `2_원래이름` 형식으로 구분하며 프레임과 현재 값을 유지합니다. 고정 메쉬와 스킨 메쉬를 함께 넣을 수도 있습니다.
- **프리팹으로 묶기:** 메쉬와 Renderer를 각각 유지하면서 한 프리팹에 저장합니다. 렌더링 설정이 서로 달라 병합할 수 없는 경우에도 이 방식을 사용할 수 있습니다.

두 방식 모두 원본별 독립 본 계층과 지원 PhysBone/Constraint를 복사합니다. 같은 이름의 본을 이름만으로 합치지 않으며, 공유 본도 원본별로 독립 복사됩니다. 현재 월드 배치를 첫 번째 원본의 위치·회전 기준으로 보존합니다. 서로 다른 아바타에 대한 실시간 추종/휴머노이드 리타기팅, Animator 이식, 복사 범위 밖 Constraint 참조의 자동 해결은 포함하지 않습니다. 본 없는 메쉬의 물리/Constraint 복사는 지원하지 않습니다. 병합 후 외부 애니메이션의 Renderer/쉐이프키 경로는 자동 변경하지 않습니다.

저장 폴더와 이름을 지정한 뒤 미리보기 또는 프리팹 저장을 누릅니다. 프리팹으로 묶기는 메쉬 에셋 여러 개, 메쉬 하나로 병합은 메쉬 에셋 하나를 생성합니다. 기존 출력은 덮어쓰지 않습니다. 다중 메쉬 출력에는 부분 선택 레시피를 생성하지 않습니다.

자동으로 생성된 프리팹 이름도 입력칸에서 바로 수정할 수 있습니다. 수정하면 직접 입력 모드로 전환하여 이름을 보존합니다. 자동 이름을 다시 누르면 의상 이름 기준으로 다시 생성합니다.

샵 브랜드는 **FORMORI / 포모리 / フォモリ**입니다. `FORMORI > Accessory Extractor`로 실행합니다.

기본 **간단 모드**는 `1. 원본 → 2. 메쉬 선택 → 3. 출력 설정`입니다. 원본을 지정하면 모든 머티리얼 슬롯의 전체 면을 선택하고, 스킨 메쉬의 웨이트 본과 연결 부모·PhysBone·지원 Constraint를 자동 추적해 새 프리팹에 복사합니다. 원본은 유지합니다. 본 없는 메쉬는 고정 메쉬로 복사하며 간단 모드의 MA 부착은 스킨 메쉬에서만 사용합니다. 외부 참조·몸 관절 리타기팅 등 기존 지원 제한은 그대로 검사합니다.

**심화 모드**는 기존 브러시·박스·아일랜드·UV 부분 선택, 수동 본·부착점, 위치·회전, 레시피 기능을 제공합니다. 간단 모드로 전환하면 전체 선택과 자동 본 추적을 적용하고 오프셋 및 Collider 제외 설정을 초기화합니다. 이름과 저장 폴더는 유지합니다.

상단에서 한국어 / English / 日本語를 선택합니다. 설정 창·메쉬 편집 창·주요 검사 메시지에 적용하며 언어를 기억합니다. 원본 → 메쉬 선택 → 본 및 부착 → 출력 설정의 네 영역으로 구성됩니다.

출력 설정에서 폴더를 드래그하거나 **찾기**로 현재 프로젝트 Assets 내부의 기존 폴더를 지정합니다. 폴더는 프로젝트별로 기억하며 저장 시 다시 묻지 않습니다. 이름별 하위 폴더에 프리팹·메쉬·레시피·검사 결과를 저장합니다. 동명 결과는 덮어쓰지 않고 고유 경로를 만듭니다. 레시피 v2는 이름 모드를 저장하며 이전 v1 레시피는 저장된 이름을 직접 입력 이름으로 복원합니다.

## 여러 오브젝트 각각 분리

메인 창 1번 카드의 **여러 오브젝트 각각 분리**를 켭니다. Hierarchy에서 의상 루트나 개별 메쉬를 선택하면(여러 개 가능, 자식 메쉬 포함) 창에 메쉬 목록이 표시됩니다. **검사**로 메쉬별 결과를 확인한 뒤 **프리팹 저장 (N)**을 누르면, 메쉬마다 악세사리 프리팹을 하나씩 저장 폴더에 만듭니다. 설정은 간단 모드와 같습니다(전체 면, 자동 본 추적, 외부 Collider 제외). 실패한 메쉬는 건너뛰고 이유를 결과에 표시합니다.

## 사용 순서

1. 씬의 원본 Renderer와 아바타 루트를 지정합니다. 한 번에 Renderer 하나를 처리합니다.
2. **출력 설정**에서 자동 이름(의상·헤어 이름 참조) 또는 직접 입력을 선택합니다. 직접 입력한 이름은 자동 이름으로 전환했다 돌아와도 유지됩니다. 원본을 지정하면 전용 Scene 편집 창이 열립니다. 다시 열 때는 **메쉬 편집**을 누릅니다.
3. 편집 창에서 A 전체 선택, L 연결 아일랜드, B 박스, C 브러시, F 맞춤을 사용합니다. 면·박스는 Shift 추가, Ctrl 제외, 일반 선택은 교체입니다. 브러시는 Shift 없이 획을 누적하며 Ctrl로 제외합니다. Alt+드래그와 휠로 시점을 조작합니다. 관통 선택은 가려진 면도 포함하며, 박스·브러시는 면 중심 기준입니다. 설정 창의 **UV로 선택**을 펼치면 UV 선택도 사용할 수 있습니다.
4. 같은 UV에 겹친 면은 후보 버튼 또는 머티리얼 슬롯 필터로 구분합니다. UV가 없으면 Scene에서 선택합니다.
5. 스킨 메쉬는 기본으로 **본 포함 복사**가 선택됩니다. **웨이트로 본·부착 위치 자동 추적**을 켜면 필요한 본과 부모 연결을 계산하고 본 루트·부착 대상·복사 수를 표시합니다. PhysBone 계층은 웨이트 없는 끝 본도 보존합니다. 자동 추적을 끄면 본 루트와 부착 대상을 직접 지정할 수 있습니다. 본 없이 현재 모양만 사용할 때는 **고정 악세사리**를 선택합니다.
6. 검사에서 오류를 해결합니다. 간단 모드는 복사 범위 밖의 몸 Collider를 자동 제외하고 경고로 알립니다. 심화 모드에서는 외부 Collider 제외를 직접 선택합니다.
7. 미리보기에서 원본과 결과, 위치·회전·균일 크기를 확인합니다.
8. 출력 설정에서 저장 폴더를 지정한 뒤 **프리팹 저장**을 누릅니다. 선택한 이름의 새 하위 폴더를 만들며 기존 결과는 덮어쓰지 않습니다.
9. 저장 후 씬에 추가 옵션을 사용하면 새 결과 인스턴스를 배치합니다. 기존 악세사리는 자동 제거되지 않습니다.

**결과 위치**(출력 설정): **원본 따라가기**는 원본과 같은 자리에 붙어 원본 본을 따라 움직입니다. **바닥(원점)에 놓기**는 원본 위치를 무시하고, 아바타 기준으로 반듯하게 세운 결과를 바닥 중앙(가로 중앙, 가장 낮은 점이 높이 0)에 저장합니다. 저장 후 씬에 추가하면 아바타 발밑(아바타가 없으면 월드 원점)에 놓이며 원본 본을 따라가지 않습니다. MA 부착과 몸 관절(Merge Armature) 결과는 아바타에 붙어야 동작하므로 항상 원본 따라가기로 저장합니다. 여러 오브젝트 각각 분리와 한 프리팹으로 분리에도 같은 옵션이 있습니다.

## 두 추출 방식

| 방식 | 적합한 예 | 결과 |
|---|---|---|
| 고정 악세사리 | 머리핀, 브로치 | 현재 편집 포즈로 베이크된 고정 메쉬 |
| 본 포함 복사 | 리본 본 가지, 흔들리는 체인 | 스킨 메쉬, 웨이트 본·연결 부모, 지원 PhysBone·Collider·Constraint의 새 복사본 |

고정 모드는 본 움직임과 동적 쉐이프키를 제거합니다. 본 포함 복사는 선택 정점의 모든 양수 본 웨이트와 쉐이프키의 모든 프레임을 보존합니다. 작은 웨이트도 임의로 버리지 않습니다. 원본 본을 이동하거나 삭제하지 않고 새 프리팹 내부 본으로 다시 연결합니다. 별도 오브젝트에 배치된 PhysBone도 제어 루트를 따라 복사합니다. Play Mode 또는 Animation Mode에서는 생성할 수 없습니다.

Unity 및 VRC의 Parent / Position / Rotation / Scale / Aim / LookAt Constraint도 복사합니다. 별도 호스트의 VRC Constraint는 TargetTransform을 따라 찾고, Source·Target·Up 참조를 복사된 Transform 또는 부착점으로 연결합니다. 본 가지 안의 드라이버와 연결 부모는 자동 포함합니다. 가중치·오프셋·축·활성 상태를 보존하며, 검사에 복사 Constraint 수를 표시합니다. 복사 범위 밖의 참조를 임의의 고정 본으로 대체하지는 않습니다.

Constraint 대상의 부모 좌표계도 유지되어야 합니다. 대상의 부모가 복사 범위와 부착점 밖에 있거나, 부착점 자체를 제어하는 Constraint는 차단합니다. 이런 경우에는 부모를 포함하도록 본 루트와 부착 대상을 지정해야 합니다.

## 저장되는 파일

- `.prefab`: 일반 프리팹 또는 MA Bone Proxy 부착 프리팹.
- `.mesh.asset`: 분리된 새 메쉬.
- `.recipe.asset`: 원본 식별 정보, 선택 면, 본·부착 설정.
- `.validation.json`: 저장 시점의 검사 결과.

머티리얼·텍스처는 기존 프로젝트 에셋을 참조합니다. 원본 FBX·메쉬·머티리얼은 수정하지 않습니다. 다른 프로젝트로 옮길 때는 Unity Export Package의 의존성 포함 옵션 등으로 필요한 머티리얼·텍스처와 SDK·MA 의존성을 함께 처리해야 합니다. 결과 파일은 원본 소재의 이용 조건을 따릅니다.

레시피를 불러오려면 같은 원본 Renderer·아바타 루트를 지정한 뒤 레시피를 선택합니다. 원본 메쉬나 경로가 달라졌으면 재선택해야 합니다. 임시 메쉬로 만든 레시피는 휴대용 복원을 지원하지 않습니다.

## 지원 범위

- 기존 삼각형 단위 선택이며 새 절단면을 만들거나 구멍을 메우지 않습니다.
- 삼각형 토폴로지와 읽을 수 있는 메쉬를 사용합니다. 필요한 경우 원본 임포트 설정에서 Read/Write를 직접 확인합니다.
- 여러 몸 관절에 웨이트된 메쉬는 메쉬가 쓰는 아마추어를 복사하고 MA Merge Armature로 아바타 몸에 합칩니다(Modular Avatar 필요). 결과 프리팹은 아바타 루트 아래에 둡니다. 의상 Armature와 아바타 Armature에 동시에 웨이트된 메쉬는 지원하지 않습니다.
- 원본의 FX 토글·기믹 애니메이션과 Contact 기믹은 복사본에 연결되지 않으며 검사에서 경고로 알립니다.
- 한 부착점에 붙는 악세사리는 그 본 가지만 복사하고 부착 본(Head, Chest 등)의 움직임을 따릅니다. 자동 모드에서는 다른 Renderer가 공유하는 본도 원본을 유지하며 독립 복사합니다. 수동 모드는 지정한 본 가지만 복사합니다.
- 음수·비균일 스케일은 정확한 보존을 보장하지 않아 생성을 차단합니다. 양수 균일 스케일과 회전·이동을 지원하며, FBX에서 생기는 아주 작은 스케일 오차는 무시합니다.
- 기존 Animator, Contacts, 사용자 스크립트와 복잡한 기믹은 이식하지 않습니다. 복사 범위 밖의 오브젝트를 참조하는 Constraint는 검사에서 차단됩니다. 다른 아바타 체형으로의 리타기팅은 지원하지 않습니다.
- 결과가 다른 아바타의 체형에 자동 피팅되지는 않습니다. 부착 대상과 위치·크기를 조정하세요.
- MA 부착 결과는 빌드할 때 MA Bone Proxy가 결과 프리팹 루트째 부착 본 밑으로 옮깁니다. 토글(원클릭 인벤토리 등)은 결과 프리팹 루트에 직접 거세요. 결과물을 폴더 같은 다른 오브젝트 아래에 넣고 그 부모를 토글하거나, Bone Proxy를 Content 같은 자식으로 옮기면 업로드 후 꺼지지 않습니다.
- 모자처럼 본 하나에만 100% 웨이트된 메쉬를 MA 부착으로 저장하면, Bone Proxy와 메쉬를 **오브젝트 1개**로 저장합니다(본 하나면 오브젝트 1개로, 기본 켜짐). 셰이프키가 없으면 일반 MeshRenderer가 되어 스킨드 메쉬 수가 줄어듭니다. 본이 2개 이상이거나 PhysBone·Constraint가 있으면 지금처럼 본 계층째 저장합니다.
- Ctrl+Z는 선택과 씬 배치를 되돌립니다. 저장한 에셋 파일을 삭제하는 기능은 아닙니다.
- 저장 결과가 원본 씬 오브젝트를 참조하지 않더라도, 원본 머티리얼·텍스처 에셋의 의존성은 남습니다.
